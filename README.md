# Posta hut

Learn to recognise the longsword guards of historical European martial arts (HEMA): the *Hut* of the German
tradition and the *posta* of the Italian. Name the guard, or find it — with 3D fencers or the original
manuscript plates.

**Play:** https://crashingtingler.github.io/posta-hut/

Masters: Johannes Liechtenauer, Fiore dei Liberi and Joachim Meyer.
